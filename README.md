# Malayalam Handwritten Character Recognition

A Deep Learning-based character recognition system built to classify handwritten Malayalam characters.

## 📌 Project Overview
This project uses a Convolutional Neural Network (CNN) to recognize and classify 85 distinct Malayalam characters from images. It was built from scratch using Python and TensorFlow/Keras.

## 📊 Key Results
- **Total Images Preprocessed:** 17,235 training images
- **Number of Classes:** 85 characters
- **Test Accuracy:** 87.28%

## ⚙️ Technologies Used
- **Language:** Python
- **Deep Learning Frameworks:** TensorFlow, Keras
- **Data Processing:** NumPy, Pandas
- **Model Architecture:** Convolutional Neural Network (CNN)
